    dibu · editor de diagramas
    
    
    Escribí bloques YAML o JSON con un campo type y la vista previa se actualiza mientras escribís. Todo se procesa en tu navegador: el motor dibu está compilado a WebAssembly y no se envía nada a ningún servidor.
    
    
      
      
    • YAML / JSON: una lista de bloques (- type: …), un bloque suelto o {blocks: [...]}. Cada elemento de la lista se renderiza por separado.
      • 
      
    • Markdown: cada fence ```dibu (o ```estructura, ```statics) genera un SVG apilado, con el mismo nombre estructura-<hash>.svg que produce dibu sync-md. Con texto, la vista previa muestra el documento entero: el resto del Markdown entre los diagramas.
      • 
      
    • PlantUML: en Markdown, los fences ```plantuml o ```puml se dibujan con PlantUML compilado a JavaScript (TeaVM), también dentro del navegador. Sin @startuml el bloque se envuelve solo, y las opciones de alucarD (// [ancho, 60%]) se ignoran. Un archivo .puml se abre como PlantUML: un diagrama por cada @start…/@end…. El theme Oscuro usa el modo oscuro de PlantUML; el motor se carga con el primer diagrama.
      • 
      
    • Imprimir… (en Markdown): una vista de impresión a pantalla completa, sin el editor, con el documento listo para imprimir o guardar como PDF desde el diálogo del navegador. «Encabezado y pie…» define el texto de arriba y de abajo de cada página, con el título, la fecha y el número de página. Esc vuelve al editor.
      • 
      
    • Hacé clic en un diagrama para ir a su bloque en el editor; al mover el cursor se resalta el diagrama correspondiente.
      • 
      
    • Themes: los botones Tinta, Color, Contraste y Oscuro eligen el theme de todos los diagramas (lo mismo que dibu --theme). Un bloque puede elegir el suyo con theme: dark o con un objeto {extends, colors, typography}; se exporta tal como se ve.
      • 
      
    • Visual (Ctrl+E): editá el diagrama seleccionado con formularios. Los campos sugeridos salen de los ejemplos y del código del motor; arrastrá la etiqueta de un número para variarlo en vivo. Los cambios se escriben en el código al instante. Un bloque PlantUML se edita en una caja de texto, con la línea del error de sintaxis marcada.
      • 
      
    • Asistente: al escribir una clave o un valor aparecen sugerencias tomadas de los ejemplos y del código del motor (Ctrl+Espacio las fuerza). Elegir el type de un bloque vacío lo completa con los campos de ejemplo (Shift+Enter: sólo el tipo). La barra inferior describe el campo bajo el cursor y avisa si no lo reconoce.
      • 
      
    • Edición: Alt+↑/↓ mover líneas · Shift+Alt+↑/↓ duplicar · Ctrl+/ comentar · Ctrl+Shift+K borrar línea · Enter mantiene la sangría y continúa listas.
      • 
      
    • Atajos: Ctrl+S guardar · Ctrl+O abrir · Ctrl+Enter renderizar ya · Tab/Shift+Tab indentar.
